# SIN RECETA · Estudio creativo

Web oficial de **SIN RECETA**, estudio creativo de Pucallpa, Perú.

**Servicios:** Producción audiovisual, Community Manager y Desarrollo Web.

**Stack:** HTML, CSS y JavaScript — sitio estático compatible con Vercel.

## Publicación del proyecto

El sitio completo se entrega en el paquete `SIN_RECETA_WEB_GITHUB_VERCEL_FINAL.zip` de la conversación. Hay que **descomprimirlo y subir todos los archivos y carpetas** al directorio raíz del repositorio: `index.html`, `styles.css`, `app.js`, `vercel.json`, `assets/img/` y `assets/video/`.

**Importante:** no subir únicamente el ZIP. Los cuatro MP4 y sus imágenes son necesarios para el portafolio.

En [Vercel](https://vercel.com/new), importar este repositorio, seleccionar framework **Other** y usar directorio raíz `./`, sin comandos de compilación. Se asignará una URL pública `.vercel.app`.

Antes de poner el sitio comercial en producción, verificar permisos para mostrar los trabajos de los clientes y el plan Vercel compatible con uso comercial.
